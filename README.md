# DigiPet — 바탕화면 방치형 포켓몬 키우기

다마고치 + 디지몬 스타일의 **로컬 방치형 게임**입니다. 알을 키워 진화시키고, 타입 상성이 있는 전투를 자동(또는 직접)으로 하고, 포켓몬을 포획해 **1세대 151종 도감**을 채웁니다.
미니 모드로 바탕화면 작업표시줄 위를 돌아다니게 두고, 다른 프로그램을 하면서 방치할 수 있습니다.

- Windows 전용 (트레이·창 제어에 Win32 API 사용), Python 3.11+ / 추가 설치 없음 (tkinter 기본 포함)
- 꺼 둔 동안에도 최대 8시간까지 성장·전투가 진행됩니다.

## 실행

| 방법 | 설명 |
|---|---|
| `start.bat` 더블클릭 | 콘솔 창 없이 실행 (`pythonw`) |
| `python digipet.py` | 콘솔로 실행 |
| `python digipet.py --fast` | 시간 60배 (테스트용) |

이미 실행 중일 때 다시 실행하면 새로 켜지지 않고 기존 창을 앞으로 불러옵니다.
오류가 나면 `crash.log` 에 기록됩니다 (게임은 계속 진행).

## 화면과 조작

**전체 화면 모드**: 화면(스크린) + 버튼 10개

| 버튼 | 기능 |
|---|---|
| 먹이 | 고기(+30) / 간식(5 Bits, 친밀도 +8) |
| 훈련 | 힘·속도·지능 훈련 (기력 소모, 경험치 +2) |
| 배틀 | 전투 시작 (자동 전투가 기본, 전투 중 버튼을 누르면 직접 조작) |
| 재우기/깨우기 | 잠들면 기력이 약 20분에 걸쳐 회복 |
| 치료 | 병 치료 (만병통치약 또는 15 Bits) |
| 가방 | 보유 아이템 사용 |
| 상점 | 아이템 구매 / 영구 강화 — 팝업 대신 도감 틀의 게임 화면이 상점 화면으로 바뀜 (항목에 마우스를 올리면 설명) |
| 도감 | 1세대 151종 도감 (15칸씩 11페이지, `◀ ▶` 클릭 또는 마우스 휠) |
| 상태 | 타입·등급·능력치·진화 조건 확인 |
| 설정 | 메뉴 (우클릭과 동일) |

- **펫 클릭**: 쓰다듬기 (친밀도 +1, 숫자는 표시하지 않음)
- **더블클릭**: 전체 화면 ↔ **미니 모드** (펫만 투명 배경으로 표시, 창 크기 320×230으로 전체 모드와 펫 크기가 같음)
- **우클릭**: 설정 메뉴 (모드 전환, 창 설정, 바닥으로 내리기, 알림 소리, 볼 던지기, 환생, **전체 초기화**, 종료). 상점·상태·도감은 전체 모드의 버튼으로 엽니다. 돌아다니기·자동 배틀·자동 돌봄·자동 포획·전투 창 항목은 사용자에게 보이지 않고 항상 기본값(켜짐, 전투 창은 미니 모드만)으로 동작합니다.

### 바탕화면 돌아다니기 (미니 모드)
펫이 작업표시줄 위를 따라 좌우로 걷고 가끔 멈춥니다. 펫 그림 부분만 클릭되고 투명한 부분은 뒤의 프로그램으로 클릭이 전달됩니다.
펫을 끌어 높이를 바꾸면 그 높이로 걷습니다 (우클릭 → "펫을 바닥으로 내리기"). 전투/수면 중에는 멈춥니다.

### 전체 초기화 (우클릭 → 전체 초기화)
펫·Bits·도감·가방·영구 강화·세대·전적을 모두 지우고 1세대 새 알로 처음부터 시작합니다 (창 위치·투명도 같은 설정은 유지). 확인을 **두 번** 거치며, 실수에 대비해 직전 저장을 `save.json.reset-backup`으로 한 부 남깁니다 (다음 초기화 때 덮어씀). 되살리려면 그 파일 이름을 `save.json`으로 바꾸세요. (`새 알로 환생`은 Bits·도감·가방·강화를 유지하는 다른 기능입니다.)

### 창 설정 (우클릭 → 창 설정)
- **창 위치**: 항상 위 / 보통 / 항상 아래 (다른 창 뒤, 바탕화면 위)
- **투명도**: 100 / 80 / 60 / 40 / 25 %
- **클릭 통과**: 창이 마우스를 완전히 무시 (아래 단축키로 해제)

### 시스템 트레이 / 단축키
트레이 아이콘: 좌클릭 = 숨기기/보이기, 더블클릭 = 앞으로, 우클릭 = 메뉴(배틀 시작·미니 모드·클릭 통과·종료).

| 단축키 | 기능 |
|---|---|
| `Ctrl+Alt+P` | 창 되찾기 (숨김 해제 + 클릭 통과 해제 + 화면 안으로 + 맨 앞으로) |
| `Ctrl+Alt+D` | 클릭 통과 켜기/끄기 |

창이 숨겨져 있거나 "항상 아래"일 때 배고픔·아픔이 생기면 트레이 풍선으로 알려 줍니다.

## 포켓몬과 알 부화

- **종**: 1세대 151종 전부 + 기존 계통에 쓰던 21종(피츄, 토게피 계통, 에브이/블래키, 애버라스 계통, 랄토스 계통, 리오르·루카리오, 아공이 계통, 메리프 계통). 진화 계통(단독 포함) **85개**. 메가/거다이맥스 등 특수 형태는 없음.
- **타입**: 18타입(페어리·강철 포함, 최신 기준)이 모든 종에 있습니다.

### 부화 확률
알은 **바로 부화**합니다 (계통 선택권이 있을 때만 사용 여부를 확인할 때까지 기다림 — 아래 참고). 부화할 때 **등급 → 계통** 순서로 뽑습니다.

| 등급 | 확률 | 계통 수 | 예 |
|---|---|---|---|
| ★ 일반 | 60% | 33 | 구구, 꼬렛, 주뱃, 디그다 … |
| ★★ 희귀 | 28% | 33 | 파이리·꼬부기·이상해씨, 피츄, 이브이, 가디, 포니타 … |
| ★★★ 매우 희귀 | 10.5% | 14 | 미뇽, 라프라스, 프테라, 잠만보, 암나이트, 투구, 폴리곤, 애버라스, 아공이 … |
| ★★★★ 전설 | 1.5% | 5 | 프리져, 썬더, 파이어, 뮤츠, 뮤 |

- 등급 안에서는 균등 추첨 (그래서 전설 한 종은 약 0.3%).
- **이로치(색이 다른 개체)**: 별도로 1/40(2.5%). ✨ 표시와 다른 색 그림, 전투력 +3.
- **행운의 부적**(강화): 레벨당 희귀 이상 등급 확률 +15%, 이로치 확률 +10%.
- **계통 선택권**(1,500 Bits): 알에게 쓰면 계통을 직접 고를 수 있습니다. **전설/환상의 포켓몬(썬더·프리저·파이어·뮤츠·뮤)은 목록에서 제외**되어 고를 수 없습니다(무작위 부화에서만 나옴).
  - 선택권이 **있으면** 알이 부화하지 않고 "사용할까요?" 확인창이 뜹니다. **예** → 계통 선택, **아니오**(또는 선택 창의 "무작위로") → 선택권은 아끼고 바로 부화.
  - 선택 창을 그냥 닫으면 계속 대기합니다 (알을 클릭하면 다시 물어봄).
  - 선택권이 **없으면** 확인 없이 알이 바로 부화합니다.
- 진화하지 않는 종(예: 뮤, 잠만보)은 부화하면 바로 최종 단계입니다. 2단 진화 종은 1진화부터 시작합니다.

## 성장과 진화

단계: 기본 → 1진화 → 2진화. **진화 조건 = 시간 + 경험치(EXP)** 를 둘 다 충족.

> **부화와 진화는 프로그램이 켜져 있을 때만** 일어납니다. 꺼 둔 동안 조건을 채워도 진화하지 않고, 프로그램을 켠 뒤 **15초 후**에 진화/부화가 진행됩니다.

| 단계 | 필요 시간 | 필요 EXP |
|---|---|---|
| 기본 → 1진화 | 5시간 | 386 (전투 훈련소 Lv0 기준) |
| 1진화 → 2진화 | 24시간 | 2,599 (전투 훈련소 Lv0 기준) |

**필요 EXP는 필요 시간과 연동**됩니다: 그 시간 동안의 자동 배틀(현재 간격)을 **수련장 Lv11로 전부 이기면** 시간과 EXP가 함께 채워지도록 계산합니다 (강적 비율과 강적 EXP 2배 포함). 계산식은 `필요 시간 ÷ 자동 배틀 간격 × (8+4×단계) × 1.88 × (1+강적 확률)`. 전투 훈련소로 간격을 줄이면 배틀 수만큼 필요 EXP도 늘어납니다 (예: 훈련소 Lv8이면 742 / 4,998). 수련장이 Lv11보다 낮으면 EXP가 시간보다 늦게 차고, Lv12면 조금 일찍 찹니다.

- **EXP**: 전투 승리 (8+4×단계)×수련장 보너스, 강적은 2배, 포획(×1.5, 새 포켓몬 +5), 훈련(+2). 패배·도망은 오히려 감소(아래 참고). 남은 EXP는 다음 단계로 이월.
- **분기 진화**: 이브이 — **진화의 돌**을 쓰면 불의 돌 → 부스터 / 물의 돌 → 샤미드 / 번개의 돌 → 쥬피썬더 (돌이 친밀도 조건보다 우선). 돌이 없어도 **돌봄 실수 ≤2면** 낮=에브이/밤=블래키로 진화할 수 있는데, 자동으로 진화하지 않고 **진화/유지를 묻습니다**. [아니오]로 유지하면 그 시간대에는 다시 묻지 않고, **낮↔밤이 바뀌어도 조건이 유지되면 다시 묻습니다**. 돌도 없고 돌봄 실수도 3회 이상이면 이브이로 **대기**합니다 (상태 화면에 "진화의 돌 필요"). 피카츄 → 라이츄는 **번개의 돌**을 써야만 진화합니다. 랄토스 — 힘 > 지능이면 엘레이드, 아니면 가디안.
- **변함없는 돌**: 가방에서 쓰면 진화하지 않습니다 (시간/EXP는 계속 쌓임). **다시 알로 돌아가기(환생) 전까지 유지**되고, 진화하고 싶을 땐 **상태 화면의 [변함없는 돌 해제]** 버튼으로 다시 활성화합니다 (돌은 사라짐).

## 상태

| 항목 | 설명 |
|---|---|
| 배고픔 | 단계별로 1~2시간이면 0. 0이 되면 체력 감소 |
| 친밀도 | **시작은 15** (최대 100). 켜 둔 동안(전체/미니 모드 모두) **분당 0.7** 감소(약 2시간 23분에 100→0). 배고픔 20 미만이면 2배, 병이면 4배, 둘 다면 6배, **꺼 둔 동안은 72시간에 100→0**. 클릭(+1)·승리(+2)·간식(+8)·도시락(+4)으로 상승 (포획은 +0). 훈련 -4, 패배 -16, 도망 -3, 기력 회복 아이템(활력의 가루/원기의 덩어리) 사용 -3. **15 미만이면 전투 불이익**: 전투력·전투 경험치 -25% ("심심해…" 말풍선, 상태 화면에 경고) |
| 기력 | 깨어 있으면 4시간에 100 감소. 훈련 -10, 전투 -8. 5 이하면 스스로 잠듦 |
| 체력 | 병·굶주림으로 감소 → 0이면 **사망**. 전투는 **현재 체력으로 시작하고 끝난 뒤 남은 체력이 그대로 반영**됩니다. **전투로는 죽지 않음**(최저 15) |

병은 가끔 무작위로 걸리고, 방치하면 체력이 줄어듭니다. 죽으면 클릭 → 확인 후 새 알(환생). Bits·도감·가방·강화(근력 단련 등)는 유지되고, 훈련 수치(힘·속도·지능)·경험치·돌은 새로 시작합니다.

## 전투

- **자동 배틀**: 20분마다 (체력 60↑·배고픔 30↑·기력 40↑일 때). 패배하면 40분 쉼. 전체 모드에서는 **전투 화면으로 전환**되고(미니 모드에서는 창 없이 조용히 진행되고), 펫 창에 "⚔ 전투 중!" 말풍선만 뜹니다. 결과는 메시지로 알려 줍니다.
  **전체 모드에서는 전투가 시작되면(자동 배틀이든 `배틀` 버튼이든) 도감 틀의 게임 화면이 전투 화면으로 바뀌고**, 아래 버튼 줄이 전투 명령(공격·스킬·방어·포션·도망·자동·볼)으로 바뀝니다. 전투가 끝나면 원래 화면으로 돌아옵니다. 별도 창은 열리지 않습니다. 미니 모드는 예전처럼 직접 시작한 배틀에서만 전투 창이 열립니다.
- **모든 전투는 기본이 자동**입니다 (`배틀` 버튼으로 시작한 전투도 자동). 전투 화면에서 명령 버튼을 누르면 **직접 조작**, 12초 동안 입력이 없으면 자동 진행으로 복귀, `자동` 버튼으로 즉시 복귀.
- **상대**: 1세대 포켓몬이 내 단계에 맞게 나옵니다 (기본 단계 16종 / 1진화 54종 / 2진화 81종, 전설은 최종 단계에서 아주 드물게).

### 강적 (높은 난이도)
일정 확률(기본 14% / 1진화 20% / 2진화 25%)로 **강적**이 나옵니다. 이름 앞에 `강적`이 붙고, 일반 상대보다 약 2~3배 강합니다. **전설 포켓몬은 항상 강적**입니다.

- **강화(전투력)를 올려야** 이길 수 있습니다. 자동 전투 시뮬레이션에서 승률은 근력 단련 Lv0 약 2% → Lv10 약 23% → Lv20 약 49% (훈련 30·도감 20종 기준). 상성을 노린 직접 조작과 아이템으로 더 높일 수 있습니다.
- 자동 전투는 **승산이 낮으면(내 전투력/상대 < 0.8) 도망**칩니다 ("강적에게서 무사히 도망쳤다!"). 도망이 실패해도 전투로는 죽지 않습니다.
- 강적은 포획률이 절반, 대신 보상이 큽니다: Bits ×2.5, 경험치 ×2, 돌 드롭 확률 ↑.

### 돌 줍기 (전투 승리/포획 시)
상점에는 없고 전투에서만 얻습니다.

| 돌 | 얻는 조건 | 확률 (강적) | 최대 보유 |
|---|---|---|---|
| 불의 돌 | **불꽃 타입** 적 | 12% (35%) | 3개 |
| 물의 돌 | **물 타입** 적 | 12% (35%) | 3개 |
| 번개의 돌 | **전기 타입** 적 | 12% (35%) | 3개 |
| 변함없는 돌 | 모든 적 | 5% (20%) | 2개 |

(진화의 돌은 종류별로 최대 3개. 이중 타입 적은 두 타입 각각 굴림. 가득 차면 "발견했지만 더 가질 수 없다".) 꺼 둔 동안의 전투에서도 줍고, 돌아오면 요약에 "돌 N개 획득"이 나옵니다.

### 공격과 스킬, 타입 상성

| 명령 | 효과 |
|---|---|
| **공격** | 타입과 무관한 기본 공격. 안정적, 횟수 제한 없음 |
| **스킬** | **내 타입** 기술(타입 중 상대에게 가장 효과적인 쪽 자동 선택). 상성 적용, PP 5(전투당), 명중 90%, 기본 공격보다 강함 + **타입별 이펙트** |
| 방어 | 다음 피해 60% 감소 + 체력 소량 회복 |
| 포션 | 체력 +40 / +70 (상처약·좋은상처약) |
| 도망 | 70% 성공 (패배로 집계, 페널티는 패배의 절반) |
| 몬스터볼 / 슈퍼볼 / 하이퍼볼 | 포획 (상대 체력이 낮을수록, 볼이 좋을수록 유리) |

- **상성**: 효과 굉장(×2, 겹치면 ×4) / 보통 / 별로(×0.5, ×0.25) / 효과 없음. 피해 배율은 0.3~3.0배로 제한하고 무효는 약 0.15배.
- **상대도 상성을 씁니다**: 상대의 공격은 상대 타입 중 내게 가장 아픈 타입으로 들어옵니다 (약점을 맞으면 아픔).
- 전투 창에서 이름 아래 **타입 칩**, 버튼 위에 `스킬: 물대포 [물] → 상성 ×2 (굉장함)` 힌트가 보이고, 맞힌 뒤 "효과가 굉장했다!" 같은 메시지가 나옵니다.
- **스킬 이펙트**: 18타입 각각 다른 연출 (불꽃 화염, 물 물줄기, 전기 번개, 풀 잎사귀, 얼음 결정, 격투 충격, 독 거품, 땅 솟는 바위, 비행 바람, 에스퍼 파동, 벌레 무리, 바위 낙석, 고스트 영혼, 드래곤 용의 숨결, 악 할퀴기, 강철 베기, 페어리 하트 등). 상대의 공격에도 상대 타입 이펙트가 나옵니다.
- **자동 진행의 선택**: 상성이 나쁘지 않으면 스킬, 나쁘면 공격, 위험하면 포션, 새 포켓몬이 약해지면 볼.
- **원할 때 배틀**: `배틀` 버튼 또는 트레이 메뉴에서 시작합니다 (무작위 상대. 상대를 고르는 기능은 없음).
- **새 포켓몬 포획(자동)**: 도감에 없는 상대는 체력이 **15% 이하**가 되면 **몬스터볼을 1회 반드시** 던집니다(몬스터볼이 없으면 슈퍼볼 → 하이퍼볼). 던지기 전까지는 공격이 상대 체력을 8% 아래로 깎지 않아 잡기 전에 쓰러뜨리지 않습니다. 단, 볼을 던졌다가 다음 상대 공격에 내가 쓰러질 수 있을 만큼 체력이 낮으면 볼 대신 공격해 끝냅니다. 한 전투에 자동 던지기는 1회뿐입니다. 설정의 "자동 포획"은 몬스터볼 자동 구매만 켜고 끕니다.
- **꺼 둔 동안**: 40분마다 한 번씩 연출 없이 자동 전투 처리 (최대 8시간).

| 패배 | -(6+4×단계) | -15분 | -16 |
| 도망 | -(3+2×단계) | -7분 30초 | -3 |

## 자동 돌봄 (설정에서 켜고 끔, 기본 켜짐)

Bits를 써서 알아서 돌봅니다: 배고픔 30 미만이면 급식(5 Bits), 아픈 지 2분이 지나면 치료(만병통치약 → 아니면 15 Bits),
체력 35 미만이면 상처약, 기력 25 미만이면 기력 아이템. Bits에 여유(200↑)가 있으면 상처약·활력의 가루를, 자동 포획이 켜져 있으면 몬스터볼을 보충합니다.
(48시간 방치 시뮬레이션 12회에서 사망 0, 전부 최종 진화)

## 저장과 복구

- 30초마다·종료 시 `save.json` 저장, 직전 저장은 `save.json.bak` 으로 보관.
- 파일이 깨지면 `save.json.corrupt-시각` 으로 따로 보관하고 `.bak` 에서 복구, 그것도 없으면 새 알로 시작.
- 불러올 때 이상한 값/모르는 포켓몬/계통과 안 맞는 형태는 자동으로 고칩니다. 이전 버전 저장도 그대로 이어집니다 (계통 번호는 뒤에만 추가하므로 호환).
- 처음부터 다시 시작: 게임을 끄고 `save.json` 삭제.

## exe 로 만들기

`build_exe.bat` 를 실행하면 PyInstaller 로 `dist\DigiPet.exe` (약 10MB, 단일 파일, 콘솔 창 없음, 스프라이트 포함)를 만듭니다. Python 이 없는 PC 에서도 실행됩니다.
코드나 스프라이트를 바꾼 뒤에는 **다시 빌드해야** exe 에 반영됩니다. 게임이 켜져 있으면 exe 를 덮어쓸 수 없으니 먼저 종료하세요.

- exe 로 실행하면 `save.json` 은 **exe 옆**에 생깁니다 (`python digipet.py` 로 하던 저장과는 별개).
